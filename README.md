# Rupom Personal Journal

A responsive, editorial-style personal blog for Mahmudul Haq Rupom. This is intentionally a **personal blog**, not a portfolio template.

## What's included
- `index.html` — complete homepage and section structure
- `css/style.css` — design system, day/night themes, responsive layout and section comments
- `js/main.js` — sample articles, search, category filters, article reader, theme switcher, scroll effects and navigation
- `images/` — folder for your own images

## Run the website
1. Extract the ZIP file.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet is required for Bootstrap, Bootstrap Icons, Google Fonts and the remote Unsplash demo photographs.

## Important customizations
- **Your profile photo:** replace the image URL in the About section in `index.html`.
- **Hero photo:** replace the `hero-image` URL in `index.html`.
- **Articles:** edit the `articles` array near the top of `js/main.js`. Each article has a title, category, reading time, image, summary and body.
- **Email:** currently set to `mahmudul19web@gmail.com`.
- **Social links:** replace the `href="#"` values for Facebook, LinkedIn and GitHub in `index.html` with your real profile URLs.
- **Theme:** Day mode is the default. The theme button in the top navigation switches between Day and Night, and the selection is saved in localStorage.

## Notes about demo functionality
- The six included posts are starter/demo content. They are sample writing ideas based on web development, JavaScript, AI automation and learning. Review and personalize them before publishing.
- The article reader is a front-end modal preview. For a production blog, create real article URLs or connect a CMS/backend.
- The newsletter form currently shows a demo confirmation only. Connect an email marketing service or backend to collect subscriptions.
- There is no admin dashboard or database in this static starter.
